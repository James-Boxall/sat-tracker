# Sat-Tracker
A Satellite visualisation tool built in THREE.js with a Python backend. All data is taken from CelesTrak.org  in the form of TLEs and then rendered as orbits using sgp4.
### Features
- 3d control and orbital rendering
- Satellites can be added in groups or individually
- Supports 200+ simulations running in real-time
